The research says the product should optimize safety-weighted context utility, not just the smallest string.

Target pipeline.

The artifact path keeps measurement and safety attached from ingestion through rehydration.

Safe fixture or repo context → path policy + redaction → exact TokenCounter → candidate builders → audit + deterministic graders → MemoryArtifact[] → native API → optional thin MCP server.

TokenCounter

Pluggable oracle with verified local counts first; rough estimates stay marked as estimates.

MemoryFrame

Typed, line-oriented representation for facts, decisions, constraints, actions, source spans, and confidence.

Local retrieval baseline

Deterministic JSONL/FTS-style retrieval is mandatory before cloud/graph/profile providers.

MemoryArtifact

Every result carries text, token counts, source spans, audit, scores, and provenance.

Build plan.

Four phases turn the research into a benchmarkable developer prototype before any remote provider or public product surface.

Safety + measurement

TokenCounter, model manifest, redaction, path policy, forbidden-surface scan, untrusted-memory wrapping, delete policy.

Artifact generators

MemoryFrame parser/emitter/rehydrator/audit plus extractive, compact JSON, and local retrieval baselines.

Reusable benchmark

Seeded corpus, graders, runner, analyzer, item JSONL, scorecard, and small-sample warnings.

Thin integration

Native ESM API first; MCP server adapts six benign tools with resources/prompts off and sampling disabled.

External baselines

LLMLingua, provider counts, graph/semantic/profile providers only after P0-P3 safety gates pass.

Non-negotiable safety gates.

M8 turns the product boundary into testable controls. The memory subsystem is separate from non-memory GLOSSOPETRAE surfaces.

Root confinement

Resolve file paths with realpath, deny traversal/symlink escapes, deny secret/profile paths, and cap input size.

Canary redaction

Strict mode requires redaction recall 1 for fake keys, tokens, private-key markers, cookies, and invisible canaries.

Forbidden-surface scan

The memory API/MCP/docs must expose only the benign six functions and no stealth/stego/covert examples.

Untrusted provider rows

Retrieved memory text remains quoted data and is never promoted into system, developer, or tool instructions.

Delete / forget story

Local providers must delete and purge. Remote providers skip until deletion semantics are verified.

No network by default

Provider counters and memory services are opt-in via explicit clients, never credential-file discovery.
